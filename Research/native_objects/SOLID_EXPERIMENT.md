# Solid construction 002 — bounded extension, frozen before live calls

User authorized continued work toward a working solution. Preserve construction-001
as failed visual evidence. This experiment tests a specific change: general boolean
geometry plus application-owned visual feedback. No object-specific templates,
manual numerical rescue, new object format or production integration.

General operations add/subtract solids, round corners, repeat patterns and preserve
part identity. Every output remains in the existing research package. Manifold3D
3.3.2 and NumPy 2.2.6 are pinned in an isolated Python 3.12 environment. Upstream:
https://github.com/elalish/manifold (Apache-2.0). This library does not supply object
knowledge or guarantee that an assembly is useful. There is no GPU rental.

Numerical checks include actual solid intersections, gap measurement, connected
islands and swept cylindrical passage probes. Passage probes must cross the part's
convex envelope and contain no solid obstruction; a probe in air fails. Containment
checks convex envelope membership and no solid intersection, not semantic completeness.
Original triangle-surface attachment checks and symmetry-bound checks remain.

Construction: existing OpenAI gpt-6-sol, **high** reasoning, 12,288 output tokens,
$0.16 worst-case cap per request. Independent review: same model family, medium,
2,048 output tokens, $0.05 cap. The reviewer receives request, object-only renders,
part bindings, declared relationships and failed numerical checks. It is a separate
context, not an independent model family or human. Opinion is not certification.

is now a known failure case, not a new held-out test. Exact JBL stays evidence-blocked.
