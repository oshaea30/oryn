# Spatial 008 — request intent to measured spatial constraints

Frozen before paid dispatch. Keep the original geometry executor, operation library,
connection solver, compact geometry schema and the four original requests. Add the
same static hanging-sphere concept used in the interpretation comparison.

## Change being tested

The interpreter still emits the same source-bound requirement inventory, retaining
short natural-language values and stable IDs. A small `spatial` list translates
selected `other/structure` IDs to registered checkers: seated on top, members pointing
radially outward, one component at each outward end, coincident axes, or parallel axes.
Reference entities and radial plane axes are explicit. Unmapped constraints stay
unsupported. The spatial list and fixed measurement policy are hashed with the frozen
contract. This is a research adapter, not a new object format.

The planner binds these IDs to existing parts, mates and feature ports. Coverage
checks cardinality and endpoints before geometry; final checks measure the solved
solids and geometry-backed features. Static placement does not verify physical loads,
motion, power transmission or correct identification of a part's functional axis.
No output editing, object templates, manual component repair or paid model judge.

## Frozen acceptance criteria

- Original lamp retains suspended seed inside the shade and emission; emission remains
  unsupported and must block planning. Do not remove glow to obtain a mesh.
- Drone retains four-member counts, inspect/explode, outward arms around the frame,
  one motor at each arm's outer end, and one propeller aligned to each motor. The
  latter three must receive the correct typed endpoint/operator bindings.
- Static hanging-sphere concept preserves inside/hanging, explicit static/physics
  waivers and ring seated on base. Attachment alone does not cover seated position.
- Original speaker and sharpener preserve explode/inspection and useful inferred
  main-component relationships; do not invent requested audio or animation.
- Every required ID is bound once or explicitly unsupported. Required unsupported
  blocks geometry. Face contact cannot stand in for axis alignment. One-to-one
  constraints cannot reuse targets. A valid reference does not itself prove geometry.
- Measured numeric success requires ALL original executor and new spatial checks to
  pass. Actual assembled/exploded images must then be inspected separately. Numeric
  success alone is not a visually coherent object, semantic completeness or product pass.
- Repair gets one opportunity per admitted case, with the same requirement contract,
  assembly lock, spatial operators and fixed tolerances. All first plans precede repairs.
